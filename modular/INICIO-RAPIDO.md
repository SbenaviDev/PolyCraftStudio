## ⌨️ Atajos Esenciales (Memoriza estos 10)

| Tecla | Función | Úsalo Para |
|-------|---------|------------|
| **`Tab`** | Objeto ↔ Edición | Cambiar modos |
| **`1` `2` `3`** | Vértice/Arista/Cara | Tipo de selección |
| **`G`** | Mover | Transformar posición |
| **`R`** | Rotar | Girar elementos |
| **`S`** | Escalar | Cambiar tamaño |
| **`F`** | **Crear cara** | **3+ vértices → cara** ⭐ |
| **`V`** | Añadir vértice | Crear geometría |
| **`A`** | Seleccionar todo | Selección rápida |
| **`X`** | Eliminar | Borrar elementos |
| **`Ctrl+Z`** | Deshacer | Corregir errores |

## 🎨 Tu Primera Cara - Tutorial Práctico

### Crear un Triángulo (60 segundos):

```
Paso 1: Preparar
   Tab      → Modo Edición
   1        → Modo Vértice

Paso 2: Crear Vértices
   Doble clic en espacio (×3)    → 3 vértices

Paso 3: Seleccionar
   Shift + Clic en cada vértice  → 3 seleccionados

Paso 4: Crear Cara
   F                              → ¡Triángulo creado! ✨
```

**Resultado:** Tu primera cara creada desde cero 🎉

## 🎯 Flujos de Trabajo Comunes

### Para Modelado Low Poly:
```
1. Tab (Edición)
2. Doble clic para añadir vértices
3. Selecciona 3+ vértices
4. F para crear caras
5. G/R/S para ajustar
6. Exportar como OBJ
```

### Para Editar Modelo Existente:
```
1. Importar archivo
2. Tab (Edición)
3. 1/2/3 para seleccionar elementos
4. G/R/S para transformar
5. Analizar y Reparar si necesario
6. Exportar
```

### Para Papercraft:
```
1. Importar modelo
2. Simplificar (panel decimación)
3. Analizar y Reparar
4. Exportar OBJ
5. Abrir en Pepakura
```

## 🆘 Problemas Comunes

### "No puedo seleccionar"
```
Solución: Presiona Tab para entrar en modo Edición
```

### "Los atajos no funcionan"
```
Solución: Haz clic en el canvas (área 3D) primero
```

### "No aparece el modelo"
```
Solución: Presiona Shift+F para enfocar
```

### "La cara quedó al revés"
```
Solución: Selecciona la cara → Botón "Invertir normales"
```

### "Se cerró el servidor"
```
Solución: En la terminal, ejecuta: node server.js
```

## 🌟 Funciones Destacadas

### ⭐ Crear Caras (F)
**Lo más nuevo y poderoso**
- Selecciona vértices
- Presiona F
- ¡Cara creada automáticamente!

### ⭐ Selección Múltiple
**Funciona perfectamente**
- Shift + Clic: añadir
- Ctrl + Clic: quitar
- Arrastrar: box select

### ⭐ Arrastre Directo
**Mueve sin presionar G**
- Arrastra vértices/aristas/caras
- Fusión automática de vértices
- No interfiere con selección

### ⭐ Importación Universal
**3 formatos soportados**
- OBJ: estándar
- STL: impresión 3D
- FBX: desde Blender/Maya
