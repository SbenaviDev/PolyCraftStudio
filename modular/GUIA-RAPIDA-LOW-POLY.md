# Guía Rápida: Low Poly Automático 🚀

## ⚡ Uso en 3 pasos

### 1️⃣ Importa tu modelo

```
Menú superior → Importar → Selecciona tu .fbx, .obj, .stl
```

### 2️⃣ Elige preset

Panel lateral → **Low Poly** → Selector de preset:

- **Ligero (70%)**: Conserva más detalle
- **Medio (50%)**: ⭐ Recomendado para la mayoría
- **Agresivo (30%)**: Máxima simplificación

### 3️⃣ Aplica

Haz clic en: **"Low Poly Automático para Papercraft"**

✅ ¡Listo! Verás el resultado en segundos con estadísticas de reducción.

---

## 🎯 Cuándo usar cada preset

| Tu modelo tiene... | Usa este preset |
|-------------------|-----------------|
| 📦 Pocas caras (< 5,000) | **Ligero** |
| 🎨 Detalle normal (5,000-20,000) | **Medio** |
| 🔥 Muchísimas caras (> 20,000) | **Agresivo** |
| 📸 Escaneo 3D / fotogrametría | **Agresivo** |
| 🎮 Modelo de videojuego | **Medio → Agresivo** |
| 🏗️ Arquitectura con superficies planas | **Medio** |

---

## 💡 Tips rápidos

✅ **Prueba primero con "Medio"** → Si aún tiene muchos triángulos, aplica "Agresivo"

✅ **Puedes aplicarlo varias veces** → Pero cada vez reduce más, úsalo con cuidado

✅ **Combínalo con otras herramientas**:
   1. Low Poly Automático
   2. Analizar y Reparar (si hay problemas)
   3. Triangular todo (opcional, para Pepakura)
   4. Exportar a .obj

✅ **Deshacer**: Si no te gusta el resultado → **Ctrl+Z**

⚠️ **Guarda el original** antes de aplicar presets agresivos

## ❓ FAQ Ultra-Rápida

**¿Pierdo detalles?**
Depende del preset. Medio es seguro. Agresivo simplifica más.

**¿Puedo deshacer?**
Sí, Ctrl+Z inmediatamente después.

**¿Triangulo después?**
No es necesario, pero puedes si prefieres.

**¿Para qué sirve exactamente?**
Para que modelos complejos se vean bien en Pepakura con menos piezas.
